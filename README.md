# GBC_N2fix_DOP
This repository holds the source code, necessary model input files, and model output files for the inverse model of the ocean phosphorus cycle that assimilates marine N2-fixation rate measurements to diagnose marine N2-fixation rates and patterns including that which is supported by DOP uptake vs DIP uptake.

Three model architectures are included and described below. For each of the three models, five unique solutions are included and can be generated by altering the line of code that reads:

    obs_N2.Jfix = obs_N2.Jfix ./ 20.0 # convert to P units with Diaz N:P = 20:1
to a value of 30.0, 40.0, 50.0, or 60.0 in increments of 10, which are the prescribed diazotroph biomass N:P stoichiometry.

Base Model = Iron limitation term on diazotrophy is a normalized function of the euphotic zone dissolved [Fe] distribution as simulated by the inverse model-data product of Pasquier, B., & Holzer, M. (2017). Inverse-model estimates of the ocean's coupled phosphorus, silicon, and iron cycles. Biogeosciences, 14(18), 4125-4159. A temperature limitation term on diazotrophy is included based on a logistic equation with one optimizable reference temperature parameter. Diazotroph P uptake is based on the spatial pattern and magnitude of DIP and DOP concentrations. 

P* Model = Analogous to the Base Model but adds a dependency on diazotroph DIP uptake to that of the P* tracer within the euphotic zone, restricting diazotroph DIP uptake to where P* is positive and scaling diazotroph DIP uptake higher at higher P*.

Base no Temp Model = Analogous to the Base Model with the temperature limitation term on diazotrophy removed.
